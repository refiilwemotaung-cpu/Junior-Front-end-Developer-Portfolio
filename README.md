A modern, dark-themed portfolio website built with React, showcasing my journey as a frontend developer. Features a sleek design, smooth animations, and a collection of projects that demonstrate my skills in modern web development.

## 🌐 Live Demo

[View Live Portfolio](https://option-1-portfolio.vercel.app/)

## ✨ Features

- **🎨 Modern Dark Theme** - Elegant color palette with professional aesthetics
- **📱 Fully Responsive** - Optimized for all devices and screen sizes
- **⚡ Fast Performance** - Built with React for optimal user experience
- **🎯 Interactive UI** - Smooth animations and hover effects
- **📧 Contact Integration** - Direct email functionality
- **📄 Resume Download** - Printable PDF resume with multiple formats
- **🏆 Certifications Showcase** - Dedicated section with downloadable certificates
- **🔍 Project Filtering** - Filter projects by technology stack

## 🛠️ Technologies Used

### Frontend

- **React.js** - Component-based UI library
- **CSS3** - Custom styling with CSS Grid and Flexbox
- **HTML5** - Semantic markup
- **JavaScript (ES6+)** - Modern JavaScript features

### Design & Icons

- **Custom CSS** - No external UI frameworks
- **CSS Variables** - Consistent theming
- **Emoji Icons** - Cross-platform compatible icons

### Development Tools

- **Create React App** - Project bootstrap
- **Git & GitHub** - Version control
- **VS Code** - Development environment

## 🚀 Quick Start

### Prerequisites

- Node.js (version 14 or higher)
- npm or yarn

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/refiilwemotaung-cpu/portfolio.git
   cd portfolio
   ```

## 🚀 Deployment

### Deploying to Vercel

1. **Push your code to GitHub**
   ```bash
   git add .
   git commit -m "Deploy portfolio"
   git push origin main
   ```
